## 实现说明

### 数据与迁移

- 注册连续 v4 migration，创建 `users`、`audit_events`，并为阅读清单、聊天、练习、论文导入者和 LLM 用量增加用户归属。
- 旧私有数据和手工导入论文迁移给唯一 `admin`；自动抓取论文导入者保持空值。
- 数据库约束和服务层共同保护唯一 admin，禁止删除、停用、改名、降级。
- migration 使用进程内锁和 `fcntl.flock` 跨进程锁；迁移前创建一致性 SQLite 快照。
- 旧 settings 管理密码迁入 admin 后逐字段删除，并在写 settings 前备份。
- 新增 `source/settings/strict_io.py`，供安全迁移进行严格、原子 JSON I/O。
- 已加入 bootstrap 临时密码的“数据库提交后才可领取”状态，`create_app()` 用 `finally` 获取并记录一次，目标是避免 settings 收尾失败导致密码永久丢失。

### 认证、授权和隔离

- 登录统一为用户名和密码；实现成员邀请、一次性临时密码、首次改密阻断、管理员重置、启停和永久删除。
- Flask session 保存 user id/version，30 天滑动有效；密码变化、重置、停用或删除会撤销旧 session。
- 实现统一登录失败文案、IP + 规范化用户名限流、全站 unsafe 方法 CSRF。
- 所有非静态路由显式分类为 public/member/admin；API 未登录返回 401、权限不足返回 403。
- 阅读清单、聊天、练习、答案、苏格拉底会话、进度和 LLM 用量均按当前 principal 隔离，不信任客户端 user id。
- 成员分析更新只接受 `rating`、`tags`；其他字段返回 403。
- 旧 `/api/paper/add` 已改为 admin-only，避免成员借兼容端点覆盖摘要或价值简评；成员通过 import preview/import 流程导入公开论文。
- 进度任务 id 已增加 owner 冲突保护；线程池 AI 用量使用 `copy_context()` 传播当前用户。

### 论文删除、审计、UI 和备份

- 单篇和批量论文删除保护已下沉到 storage 的单一 `BEGIN EXCLUSIVE` 事务，避免 impact 检查与删除之间的 TOCTOU。实现初始使用 `BEGIN IMMEDIATE`，但并发测试发现 WAL 模式下 IMMEDIATE 的写锁在首个写语句才获取、读检查阶段不阻塞并发写入，存在检查-删除竞态；改为 `BEGIN EXCLUSIVE` 后由 `tests/test_paper_delete_protected.py` 的并发测试锁定。
- 默认删除存在私有数据的论文返回 409；管理员 UI 已增加影响统计、确认及 `force=true` 重试；批量删除跳过受保护论文。
- 用户管理、审计日志、首次改密页面、登录用户名、角色化导航和操作入口已加入。
- 审计覆盖用户管理、导入、评分/标签、深度阅读、PDF、隐藏和删除；敏感公共正文使用 hash + 长度摘要。
- WebDAV manifest 已标明归档包含账号、私有学习数据和 settings secrets，并继续采用可信 WebDAV 假设。
- `README.md`、changelog、API、架构、运维、用户和 Agent 文档已更新。
