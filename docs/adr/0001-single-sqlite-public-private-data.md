# ADR 0001：公私数据共用一个 SQLite

- 状态：已接受
- 日期：2026-08-12

## 决定

公有论文数据、账号和私有学习数据保存在同一个 `papers.db`。通过表归属字段、外键约束和授权逻辑隔离数据，不拆分数据库文件。

## 理由

该方案保留论文与学习记录之间的外键、跨表事务、级联删除和 SQLite 一致性快照。WebDAV 可以原子归档完整状态，恢复时不会产生账号、论文与学习数据版本错配。

## 后果

备份包含账号及全部私有学习数据，WebDAV 必须视为可信存储。所有私有查询必须从当前 principal 注入 `user_id`，不能接受客户端提供的用户 ID。
