# ADR 0002：唯一 admin 账号是管理凭据真源

- 状态：已接受
- 日期：2026-08-12

## 决定

旧 `settings.json` 管理密码迁移为 `users.username = 'admin'` 的唯一管理员账号。`users.password_hash` 是全部账号凭据的唯一真源；settings 不再保存管理密码字段。

## 理由

统一凭据模型才能可靠实现会话版本撤销、停用、首次改密、审计和成员账号管理，避免数据库与配置文件出现两个密码真源。

## 后果

系统只允许一个 admin，且不可删除、停用、改名或降级。本机密码恢复脚本直接更新该账号并撤销旧会话。v4 迁移在数据库提交后备份并逐字段移除旧 settings 凭据。
